# Eska

I build local-first Android apps.

| Project | What it does | Downloads |
| --- | --- | --- |
| [Tidy](https://github.com/faraajs/tidy) | Converts screenshots and photos to AVIF/WebP on-device. Originals are retained by default. | [Signed APK releases](https://github.com/faraajs/tidy/releases/latest) |
| [Expense](https://github.com/faraajs/expense) | Tracks expenses locally, including parsing supported Indonesian bank and wallet notifications. AI features are optional. | [Signed APK releases](https://github.com/faraajs/expense/releases/latest) |

Source, build instructions, permissions, and verification limits are documented in each repository. Check Android and CPU requirements before installing.

For bugs and feature requests, use the project's Issues page. For security reports, use the project's private security reporting link; never post personal photos, bank notifications, transaction exports, or API keys in public issues.
